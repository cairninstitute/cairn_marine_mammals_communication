Problem Statement:
We cannot talk to whales or other marine life. As hard as our human vocal cords try, they simply stare vacantly back at us. The evidence is clear: have you tried talking to a whale? Checkmate.

But we truly lack communication with marine life. We know that these animals are intelligent. They can be trained, they can love, they can grieve, and they live completely differently from humans. 
Our work, training a machine learning model to approximate the communication of these animals, will get us closer to understanding them. 
Before, we could only play back audio that had previously been captured or recorded. 
With this project, we will be able to create fresh calls and pave the way for a future where we may conduct true conversations with marine life.
Every extra second we can generate is another second of a conversation.

Functional:
Must produce an audio file.
The produced audio file should fit within the upper and lower bounds of our hydrophone data.


Non-Functional:
Generated whale sounds should sound like whale sounds.
Generating the audio file should take less than 5 minutes to generate.
The generated audio file should be at least 3 seconds; our current goal is 15 seconds.
Passes the grade_audio_quality.py file with a C, preferably an A.


Constraints:
Must be able to run on the OSU HPC Cluster
All data needs to be in one place to run
